# Contributing

Issues and pull requests are welcome for reproducible protocol, firmware, Linux-host, simulator, benchmarking and documentation improvements.

Please:

1. keep synthetic/software results clearly separated from physical hardware claims;
2. add or update tests for behavior changes;
3. never commit API keys, broker credentials, account identifiers or private datasets;
4. do not add live-order execution to this Community Edition;
5. document hardware, OS, Python version and exact commands for benchmark claims.

By submitting a contribution, you agree that your contribution may be distributed under the repository's Apache-2.0 license.
